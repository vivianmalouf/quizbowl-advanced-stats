a site for visualizing buzzpoint statistics from quizbowl tournaments. data taken from https://2026-nationals.vercel.app/; only ACF Nationals 2026 is available for the moment. i have a long list of planned features, but feel free to make requests (particularly if you have ideas for calculated stats or data visualizations).

like 80% of this was done by Qwen3.6-35B-A3B under fairly close supervision as a bit of an experiment so there are some idiosyncracies, to say the least.
